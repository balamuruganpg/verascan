# Documentation images

All dashboard images show the built-in demo with five planted pairs, not results
from an audit of a public training corpus.

- `screencapture-127-0-0-1-8501-2026-11-04-18_19_33.png`: supplied full-page light theme.
- `screencapture-127-0-0-1-8501-2026-11-04-18_23_11.png`: supplied full-page dark theme.
- `dashboard-overview.jpg`: new capture of the dashboard header and status card.
- `dashboard-charts.jpg`: new capture of the method and benchmark distributions.
- `dashboard-match-review.jpg`: new capture after searching for `sunlight`, showing a semantic pair and its differences.
- `verascan-banner.svg` and `audit-workflow.svg`: scalable documentation graphics.

To reproduce the UI, run `verascan dashboard report.json --demo`. The supplied
full-page originals are preserved unchanged. Push these assets alongside the
README so the absolute image URLs in PyPI package metadata resolve.
